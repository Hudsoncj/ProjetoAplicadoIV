## 🎯 Objetivos e Metas

Este projeto tem como objetivo desenvolver um produto analítico capaz de modelar, decompor e prever a demanda diária de carga de energia elétrica nos subsistemas regionais do Sistema Interligado Nacional (SIN), com base em dados abertos do Operador Nacional do Sistema Elétrico (ONS).
